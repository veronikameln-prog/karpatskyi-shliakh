# Дизайн — «Карпатський шлях»

Тема «день» — варіант **A «Туман і хвоя»**. Тема «ніч» — варіант **B «Нічні Карпати»**.

Перемикач «день / ніч» міняє лише кольори. Шрифти, сітка й розміри лишаються тими самими, тому сайт впізнаваний в обох темах.

## 1. Кольори (дизайн-токени)

| Токен | День (A) | Ніч (B) | Де використовується |
|---|---|---|---|
| `--bg` | `#E9ECE8` туман | `#0E1A24` нічне небо | фон сторінки |
| `--surface` | `#F6F7F4` | `#162532` | картки, форми, модальні вікна |
| `--text` | `#1D2B24` | `#E6E1D3` | основний текст |
| `--text-muted` | `#4F5C55` | `#A9B3B0` | підписи, другорядний текст |
| `--stone` | `#8A938C` | `#1F3A3A` | рамки, лінії, дальні гори |
| `--forest` | `#2F4A3A` | `#1E3140` | ближні гори, темні блоки |
| `--accent` | `#A0552A` | `#E0A458` | кнопки, посилання, лічильник висоти |
| `--accent-soft` | `#C8743A` | `#D9C7A0` | декор: сонце / місяць, підсвітка |

**Контраст** (WCAG AA, текст ≥ 4.5:1):
- `--text` на `--bg` — понад 12:1 в обох темах;
- `--accent` на `--bg` — день ≈ 4.6:1, ніч ≈ 8:1.

Світліший `#C8743A` (≈ 3:1) тому використовується лише для декору, не для тексту.

**Реалізація:**
- значення записуються як CSS-змінні в `:root` і `.dark`;
- Tailwind бере кольори з цих змінних;
- Tailwind працює в режимі `darkMode: 'class'`;
- клас `dark` на `<html>` ставить `theme.js`, вибір зберігається в `localStorage`.

## 2. Шрифти (Google Fonts, з кирилицею)

| Роль | Шрифт | Розмір |
|---|---|---|
| Заголовки сцен | **Cormorant Garamond** 500/600 | fluid `clamp(2.5rem, 8vw, 7rem)` |
| Заголовки сторінок | Cormorant Garamond 600 | `clamp(2rem, 5vw, 3.5rem)` |
| Текст, інтерфейс | **Inter** 400/500/600 | 16–18px, міжрядковий інтервал 1.6 |
| Цифри (висота, ціна) | Inter 600, `tabular-nums` | — |

Підключаються з `display=swap` і `preconnect`, щоб текст не зникав під час завантаження.

## 3. Сітка, відступи, форми

- Контейнер — до 1200px, бічні поля `clamp(1rem, 4vw, 3rem)`.
- Заокруглення: 12px у картках, 999px у кнопок-«пігулок».
- Тіней майже немає; глибину передають шари гір і прозорість.
- Видимий фокус: обведення 2px кольором `--accent`.

## 4. Сцени головної

Шари гір — **векторні SVG-ілюстрації, згенеровані ШІ** (Claude), по 3–4 шари на сцену. Під час гортання шари рухаються з різною швидкістю — це паралакс через GSAP ScrollTrigger.

| Сцена | День | Ніч |
|---|---|---|
| Туман | світлий туман, сонце | місячне світло крізь туман |
| Ліс | смереки `--forest` | смереки силуетами |
| Полонина | м'які пагорби | темні пагорби, зорі |
| Говерла | вершина, хмари | вершина під місяцем |
| Озеро | відображення неба | відображення місяця |
| Небо | світанок | зоряне небо |

Тема змінює кольори шарів через ті самі CSS-змінні — окремих картинок для ночі не потрібно.
