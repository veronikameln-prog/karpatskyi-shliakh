# Технічний опис — «Карпатський шлях»

## 1. Карта сайту

```
index.html          Головна — сцени «від долини до вершини»
routes.html         Маршрути — каталог із data.json, фільтри, модальне вікно
planner.html        Конструктор походу — головний віджет
about.html          Про нас + поради новачкам + Контакти (форма)
```

Шапка (логотип, меню, перемикач «день / ніч») і футер — однакові на всіх сторінках.

### Головна: сцени

| № | Сцена | Текст | Висота |
|---|---|---|---|
| 1 | Туман у долині | «Карпати. Почни свій шлях» | 400 м |
| 2 | Смерековий ліс | Перший крок: ліс | 900 м |
| 3 | Полонина | Простір і хмари | 1400 м |
| 4 | Вершина Говерли | «2061 метр» | 2061 м |
| 5 | Гірське озеро | Маршрути до озер | 1750 м |
| 6 | Нічне небо, ночівля | «Склади свій маршрут» → кнопка в конструктор | 1500 м |

Закріплені елементи: шапка, лічильник висоти, крапки-навігація.

## 2. Технології

| Технологія | Навіщо |
|---|---|
| HTML5 (семантичний) | `header`, `nav`, `main`, `section`, `article`, `footer`, `dialog`, `form` |
| Tailwind CSS (CLI-збірка) | Стилі, адаптивність, `dark:` для режиму «ніч» |
| JavaScript (ES-модулі, без фреймворків) | Логіка конструктора, фільтри, валідація, тема |
| **GSAP + ScrollTrigger** (CDN) | Сцени головної, закріплені елементи, паралакс |
| **Swiper** (CDN) | Галерея фото маршруту в модальному вікні |
| `data.json` + `fetch` / `async-await` | Маршрути й відгуки |
| GitHub + GitHub Actions | Контроль версій, автоперевірки, автодеплой |
| Netlify | Хостинг, субдомен `karpatskyi-shliakh.netlify.app` |
| Netlify / Google Analytics, Open Graph | Аналітика й картка сайту в соцмережах |

Tailwind збирається CLI (а не Play CDN), щоб не втрачати продуктивність у Lighthouse.

## 5. Логіка конструктора походу

**Поля:**

| Поле | Тип | Межі |
|---|---|---|
| Регіон | select | 4 регіони + «будь-який» |
| Днів | number | 1–7 |
| Людей | number | 1–10 |
| Складність | radio | легка / середня / складна |
| Житло | radio | намет / колиба / готель |
| Опції | checkbox | гід, прокат спорядження, трансфер |

**Демонстраційні ціни (грн):**
- Харчування — 450 / особа / день.
- Житло за ніч з особи: намет 0 (власний), колиба 400, готель 1100. Ночей = днів − 1.
- Гід — 2500 / день на всю групу.
- Прокат спорядження — 250 / особа / день.
- Трансфер — 700 / особа.

**Формули:**
- `разом = (харчування + житло + прокат) × людей + гід + трансфер × людей`
- `на особу = разом / людей`, округлення до гривні.

**Підбір маршрутів:** фільтр за регіоном, складністю й кількістю днів (маршрут ≤ обраних днів). Якщо нічого не знайдено — пропозиція послабити фільтр.

**Edge cases** (обов'язкова обробка):
- порожнє поле, нечислове значення, дробові числа;
- 0, від'ємні значення, вихід за межі;
- 1 день + житло → «Ночівля не потрібна», житло = 0;
- складний маршрут на 1 день → попередження;
- 1 людина + гід → підказка, що гід вигідніший для групи;
- 0 знайдених маршрутів;
- повторне натискання.

Розрахунок винесено в чисту функцію `calculateTrip()`, щоб її можна було перевірити окремо.

## 6. Форма зв'язку

| Поле | Перевірка |
|---|---|
| Ім'я | RegEx: літери (укр/лат), апостроф, дефіс, 2–50 |
| Email | RegEx email |
| Телефон | маска `+380 XX XXX XX XX`, RegEx `^\+380\d{9}$` |
| Повідомлення | 10–1000 символів |
| Згода | обов'язковий чекбокс |

Після успіху — `form.reset()` і модальне вікно `<dialog>`. Дані нікуди не надсилаються (демо).

## 7. Доступність і безпека

- Контраст ≥ 4.5:1; `alt` у змістовних картинках; один `h1` на сторінку.
- Повне керування з клавіатури; видимий фокус.
- `prefers-reduced-motion` — без анімації сцен.
- Введення користувача виводиться лише через `textContent`.
- Ключі, паролі й персональні дані не зберігаються.
- `localStorage` містить лише вибір теми.

## 8. Сценарії взаємодії

1. **Натхнення → план.** Головна → гортання сцен → «Склади свій маршрут» → конструктор → результат → «Переглянути маршрут» → модальне вікно.
2. **Пошук маршруту.** Маршрути → фільтр «легкий, 1 день» → картка → деталі й галерея.
3. **Питання.** Про нас → форма → помилки валідації → виправлення → успіх.
4. **Тема.** Перемикач «ніч» → перезавантаження → тема збережена.
